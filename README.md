# College Student Manager

Веб-приложение для управления студентами колледжа. Проект включает:

- регистрацию и авторизацию пользователей;
- роли Admin, Manager и User;
- CRUD для студентов;
- поиск, фильтрацию и сортировку;
- просмотр статистики и отчётов;
- панель администратора;
- управление группами и специальностями;
- личный кабинет;
- адаптивный интерфейс;
- SQLite база данных через Node.js API.

## Структура проекта

- `index.html` — основная разметка интерфейса
- `styles.css` — стили и адаптивный дизайн
- `app.js` — логика приложения, интерфейс и вызовы API
- `server.js` — Express API и SQLite схема
- `college.db` — создаваемая автоматически база данных
- `package.json` — зависимости и команды запуска

## Запуск

Установите Node.js 18+ и выполните в папке проекта:

```powershell
npm install
npm start
```

Затем откройте в браузере:

```text
http://localhost:3000
```

## Демонстрационные аккаунты

- Admin: `admin@college.ru` / `admin123`
- Manager: `manager@college.ru` / `manager123`
- User: `student@college.ru` / `student123`

## Технологии

- HTML
- CSS
- JavaScript
- Node.js
- Express
- SQLite (`better-sqlite3`)

## Возможности проекта

При первом запуске сервер создаёт `college.db`, таблицы пользователей, студентов, групп и специальностей, а также добавляет демонстрационного администратора. Клиент получает данные через REST API, поэтому открывать `index.html` напрямую больше нельзя: используйте `npm start`.
